What it does

Everything on one board

Each person works their own function; the central dashboard reflects it all, live.

🗂️

Function checklists

Pre-set checklists per function with priorities. Tick an item and it auto-logs — no double entry.

📜

Live event log

Chronological, timestamped, colour-coded by source function. See who did what, when, at a glance.

⚑

Priority tasks & assignments

Outstanding work across every function, sorted High/Med/Low, each with its owner.

🚒

Resource status

Track every resource — on scene, mobile, at staging — colour-coded and updated in real time.

🗺️

Situation map

Import a site plan or photo and sketch on it. No external map service — nothing for ICT to block.

🎓

Tabletop exercises

Run training on the very tool you use for real. Facilitator injects and an exportable after-action log.

Training & exercises

The tool is the training

Because every action is timestamped, the exercise writes its own after-action report — export the full log for the debrief. No more scribbled notes.
