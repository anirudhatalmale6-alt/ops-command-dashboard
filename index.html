Map / Sketch — Planning feed

Pen:
Import a picture, then draw on it — it feeds the Map panel on the central dashboard live.

How this works

1. Import a picture. A site plan, aerial photo, floor plan or map screenshot — whatever suits the incident.

2. Sketch on it. Mark the fire ground, exclusion zones, casualty points, staging areas, access routes — using coloured pens.

3. It feeds the board. The central dashboard's Map panel updates live for everyone — no external map service, so nothing for ICT to block.

Typically the Planning function owns this, but access is configurable. Open a second tab on the dashboard to watch it update as you draw.
